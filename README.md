# Happy-Birthday-Diva

A beautiful birthday celebration page with animations, confetti, and balloons!

## Features
- Welcome screen with "Welcome home!" text and party background
- Automatic transition after 5 seconds to birthday celebration
- "HAPPY BIRTHDAY DIVA!" message with colorful rainbow background
- Animated confetti continuously falling
- Floating balloons with realistic animations
- Sparkling effects
- Background music that plays on loop (requires audio.mp3 file)

## Setup
1. Replace the `audio.mp3` file with your desired birthday music
2. Open `index.html` in a web browser

## Files
- `index.html` - Main HTML structure
- `styles.css` - All styling and animations
- `script.js` - Transition logic, confetti generation, and audio control
- `audio.mp3` - Background music (add your own music file)
